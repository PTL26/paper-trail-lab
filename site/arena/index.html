Honest Arena

Page date: 14 November 2026 · Not investment advice.

Honest Arena tests whether the most-starred open-source AI trading agent on GitHub, TauricResearch/TradingAgents, run in its default configuration the way an ordinary user would run it, earns returns beyond plain market exposure. It runs as a 12-week forward paper test: each decision is committed before the next US market open, so results cannot be chosen after the fact. Every rule — participants, costs, metrics and the pass/fail verdict — is written down and frozen before the first scored day, because a test whose rules can move after the data is seen proves nothing. This tests software; it is not a recommendation to buy, sell or hold anything.

Participants

ATradingAgents v0.7.1 (Apache-2.0), default pipeline with memory on, one model for every role (Gemini 3.1 Flash-Lite). One rating per stock per day for 10 large US stocks.
CBuy-and-hold: equal weight in the same 10 stocks, bought on day 1, never rebalanced. The benchmark A must beat.
DRandom agent: draws one of A's five ratings at random for each stock each day, with a fixed published seed. Shows what chance looks like under the same rules.
